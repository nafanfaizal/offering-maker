# Offering Letter Generator

Generator surat penawaran Discover Pangalengan berbasis HTML statis. Siap dipublish ke GitHub Pages, Netlify, Vercel, atau hosting static biasa.

## Struktur

- `index.html` - struktur surat dan UI editor.
- `styles.css` - semua styling print/PDF dan tampilan editor.
- `script.js` - upload gambar, tambah/hapus baris, dan reset PDF.
- `.nojekyll` - memastikan GitHub Pages menyajikan file statis apa adanya.

## Publish ke GitHub Pages

1. Upload semua file di folder ini ke repository GitHub.
2. Buka repository Settings > Pages.
3. Source: pilih branch utama, folder root.
4. Tunggu URL GitHub Pages aktif.

Untuk penggunaan lokal, buka `index.html` langsung di browser atau jalankan static server sederhana.
